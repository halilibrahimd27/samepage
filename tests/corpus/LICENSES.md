# Corpus sources and licenses

All files in this corpus are synthetic and written for samepage's tests (AGPL-3.0-only, same as
the project):

| Files | Source |
| --- | --- |
| `src/*.tex` → `pdf/*.pdf` | Turkish LaTeX sources in this repository, compiled with tectonic (XeTeX, Latin Modern) |
| `pdf/smoke-2pages.pdf`, `pdf/encrypted.pdf`, `pdf/javascript.pdf` | Generated by `scripts/fixtures.mjs` with MuPDF |
| `pdf/scanned.pdf` | Page 1 of `pdf/one-column-basic.pdf` rendered to a 180 dpi greyscale JPEG by `scripts/fixtures.mjs` (no text layer) |
| `docx/*.docx` | Generated by `scripts/docxFixtures.mjs` with the `docx` package |
| `pptx/*.pptx` | Generated by `scripts/pptxFixtures.mjs` with the `pptxgenjs` package |
| `expected/*.json` | Hand-written labels derived from the LaTeX sources |

The demo paper shown in the README (`media/demo-paper.tex` → `media/demo-paper.pdf`) is written
for this repository as well; its study and data are fictional.

Third-party documents (for example CC-BY papers) will be listed here with their license and URL
when added.
